02 / EVALUATION APPROACH

Make failure observable.

Good evaluation requires more than a subjective judgment about whether a response seems right.

01 / FRAME

Define the question

Identify the behavior to test and specify what would count as meaningful evidence.

02 / DESIGN

Construct the test

Develop prompts, evaluation conditions, and criteria that target the behavior under examination.

03 / SCORE

Apply the rubric

Separate observed behavior from interpretation using explicit criteria and decision rules.

04 / REPORT

Trace the finding

Document supporting turns, distinguish observations from hypotheses, and state limitations.
