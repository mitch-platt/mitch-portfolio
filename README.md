# Mitchell Platt — Portfolio Website

Static portfolio site for AWS Amplify Hosting, deployed from the GitHub `main` branch.

## Files
- `index.html` — homepage, bio, expandable project links
- `projects/behavioral-causation.html` — project page, original methodology and model interactions
- `assets/Mitchell_Platt_Resume.pdf` — download/view resume
- `styles.css` — all website styles

## Publishing
Upload these files and folders to the **root** of your existing `mitch-portfolio` repository on GitHub. Commit to `main`. AWS Amplify will publish the update automatically.

## Updating your portfolio
- Edit your homepage introduction in `index.html`.
- Add another project page under `projects/` and link to it from `index.html`.
- Replace the resume at `assets/Mitchell_Platt_Resume.pdf` when you update it.
- The Behavioral Causation page currently excludes the unfinished `XXX`/`XXXX` evaluations, and preserves existing project text and model outputs.

No separate GitHub repository, build step, runtime, or environment variables are required.
